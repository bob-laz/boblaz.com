# boblaz.com

Personal domain, hosted as a static site on GitHub Pages.

The domain mostly exists to receive email; the site is a placeholder — a
retro terminal boot sequence with a tiny interactive fake shell (`help`,
`whoami`, `about`, `contact`, `ls`/`cat`, `sudo`, `matrix`, ...) for anyone
curious enough to look up the domain behind an email address.

DNS is managed through Cloudflare (DNS-only, not proxied — GitHub Pages
handles its own HTTPS certificate for the custom domain).
